# 管理员模型设置

普通 PPT 生成只调用当前模型，不再自动调用博查等搜索服务。即使需求包含“最新、就业市场、公开来源”，也不会因缺少搜索 Key 被拦截。界面说明未联网，模型生成数值属于演示数据；旧作品的来源仍可查看。COS 继续承担已有作品存储和分享。

## 手机上使用

1. 用原邀请码登录工作台，点击“模型设置”，再输入独立管理员密码。
2. 默认使用 DeepSeek。切换兼容服务时，填写公网 HTTPS Base URL、模型名及新 API Key。保留供应商要求的 `/v1` 或代理路径，系统避免重复追加 `/chat/completions`。
3. 服务须支持 Chat Completions、Bearer 鉴权、JSON 输出。高级设置可选择 `max_tokens` 或 `max_completion_tokens`，长度上限仍由应用控制。只支持供应商兼容协议，不承诺所有模型或其他原生协议。
4. “测试连接”发起一次小型 JSON 请求，最多 20 秒，可能产生费用；不保存也不生成 PPT。“保存配置”只做本地校验，不调用模型，下一个生成请求立即生效。
5. 密钥保存后不回显；地址和服务类型不变时留空表示保留。切换地址或类型必须重新填写，防止旧密钥发给另一服务。配置并发变化会提示刷新。
6. “恢复服务器默认”明确移除网页保存的模型配置，重新使用服务器原有 DeepSeek 环境变量。模型连接测试通过不等于完整 PPT 业务验收通过。

配置与密码不存浏览器 localStorage、分享作品、Git 或镜像。管理员会话一小时，普通邀请码不能读取或修改设置。HTTPS 由现有站点提供，不需要开放新的公网端口。

## 合并后服务器准备（本 PR 不执行）

先核对合并版本和当前接收程序 SHA，通过既有 `upgrade-receiver --expected-sha256 <核实的旧哈希>` 入口升级，保留备份及恢复检查。然后在服务器可信交互终端运行：

```sh
sudo python3 "$HOME/yuling-ppt-release-review/deploy/test/bootstrap.py" model-settings --origin https://ppt-test.zhuwenjie.online
```

工具遮蔽输入两次独立管理员密码（12–200 字，不同于邀请码），只保存 scrypt 哈希。原 `app.env` 先在服务器 root/0600 下备份；仅更新管理员哈希和站点 Origin，不覆盖其他秘密。运行中网站和容器不受初始化影响；随后发布审核后的新版本，容器重建时加载新环境。

持久目录为宿主机 `/opt/yuling-ppt-test/model-settings`，UID/GID 10001、0700；容器内绑定到 `/var/lib/yuling-ppt/model-settings`，配置文件 0600。正式容器可写，候选检查只读。新客户端在上传前检查接收能力和目录是否就绪；旧程序或目录未初始化会明确停止。

重设密码须显式添加 `--reset-password`，并重新创建 PPT 容器加载新哈希，届时旧管理会话失效。重建前运行中的容器仍使用原环境；不要把只改磁盘配置描述为已撤销其会话。原邀请码和普通登录不变。

## 保存、备份与恢复

保存配置覆盖服务器默认；只有保存文件不存在时才读环境变量。文件损坏、权限不安全、解密失败均停止，不悄悄切换模型。密钥使用 `PPT_SESSION_SECRET` 经 HKDF 域隔离派生 AES-256-GCM 密钥加密。修改会话秘密前必须保留当前秘密和加密配置的受保护服务器备份，或准备重新输入 API Key；丢失秘密无法解密。

原子更新和修订号保证保存失败或旧页面不会覆盖较新配置。“恢复服务器默认”移除自定义模型及其密钥，仅留下经过认证的新版本标记；防止重置后旧页面再次命中历史版本号。模型请求开始后固定配置快照，两次尝试不会中途换服务。目录随重启、发布保留，不属于镜像或发布包。

正常恢复用管理员页面“恢复服务器默认”。文件损坏时，管理员应先在服务器安全备份损坏文件和摘要，再将损坏的 `settings.json` 移出专用目录，使用环境默认或重新保存；不要打印密钥，不删除整个目录，不触碰作品数据。任何服务器恢复另需明确授权。

地址仅允许公网 HTTPS；不支持 localhost、内网、保留地址、云元数据和重定向。DNS 返回混合内外地址也拒绝，实际连接固定到已验证地址，保持 TLS 校验。连接错误、401/403、404、超时或 JSON 不兼容应检查对应地址、密钥、模型、额度和参数，不自动换模型或增加尝试。

本轮只交付代码、模拟验证及 PR。上线后的真实 DeepSeek 大纲和完整 PPT 生成另行验收。
