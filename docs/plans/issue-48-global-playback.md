# 回收不可见全局背景与结束扫光

## 授权与目标

本计划细化所有者已批准的“保留原版视觉与缩略图，只优化资源生命周期”范围。PR #47 合并部署后，所有者用 iPhone 14 Pro Max / iOS 26 报告末页整页白屏及 Safari 重复出现问题，并无法取得设备分析记录。继续既定的范围内定位、独立 Issue/工作树、测试及审核 PR 流程；不把同意旧归档迁出视为产品变更授权，不宣称获准新的视觉取舍。所有者仍自行合并。此阶段不修改服务器或触发发布。

ADR 不新增：沿用已接受的 ADR 0016 对原版视觉、应用层兼容、资源生命周期及真机验收的决定。这是同一模块中未覆盖的全局资源回收及既有版本兼容扩展，不改变架构、公共接口、数据结构、依赖或资源预算。

## 证据与 Critic Loop

我跑过：线上完整提交为上述基点，两站及健康接口 200、无 OOM 或 pending。Windows WebKit 1x 的真实分享页百次翻页通过；3x 补测未复现崩溃，但后续数字动画恢复断言失败，必须保留并定位，不能当作通过。

3x Chromium 的受控末页实验在同一暂停时间轴和粒子画面下，仅释放完全透明的浅色背景及已经结束且完全移出视口的扫光，合成图层从 27 降到 19，drawn layer area 从 30,846,984 降到 15,374,248；三份 PNG 文件 SHA-256 完全一致。面积并非实际 GPU 内存，已确认浪费也不等于确认 iOS 崩溃唯一根因。真实作品和图像只保存在仓库外。

替代方案：保持 v2（35/100），成本低但保留已证实的不可见资源；降低模糊、粒子或取消效果（30/100），违背所有者要求；仅释放确认不可见的资源并保留原时间轴（92/100，采用），代价是额外生命周期和旧版本回归。不采用尚无根因证据的可见滤镜替换或全局 GPU 参数调整。

## 实施契约

- 淡出完全结束后，透明的非当前主题背景退出绘制；保留当前主题及原交叉淡入淡出时长、强度和颜色。
- 再进入前恢复目标背景。保存必要的动画相位数值，不保留已取消的动画对象；时间轴遵守原显示、停稳和前后台暂停规则。
- 扫光完整播放后且已完全在视口外才退出绘制；下一次章节进入仍完整播放。快速往返必须取消过期回收，不能隐藏正在重新显示的资源。
- 监听器只注册一次；不替换生产浏览器的全局动画 API。粒子算法、数量、颜色、阴影、模糊、3D、地图缩略图和文字行为不变。
- 兼容处理升级为 v3；冻结应用自有 v2 兼容字节，严格还原原始/v1/v2/v3 内容后适配。拒绝未知、篡改、重复及混合标记，保持幂等和现有失败格式。COS 原文不改。

## 验证

先在当前实现上复现隐藏全局动画和结束扫光残留。对不回收、重置相位和过期回调的故意错误分别证明拒绝，恢复后通过。覆盖普通/减弱动态效果、原始/v1/v2/v3、快速往返、转屏、地图和前后台。

原有 3x 数字恢复失败须记录实际数值与有效播放时间，区分产品时钟与测试调度；不删断言、不单纯增加等待或反复运行直到变绿。真实 sandbox iframe 路径覆盖 1x 与 3x，背景恢复后原效果仍在；固定同一画面的回收前后截图必须一致，原动态相位须另行验证，不能用静态截图代替。

运行冻结安装、validate、portable、跨仓库、十二页 geometry、生产构建、两份审计、秘密扫描、工程门禁和部署回归；最终镜像仍需严格权限、真实 Python/Chrome、完整模拟 HTTP 和两次独立十二页零差异。记录源码、版本、命令、退出码与证据摘要。代码经现有钩子推送并建立匹配 Closes #48 的 PR，三项 CI 真实通过后交由所有者审核。

## 边界及验收

不改模型、Caddy、应用秘密、正式引擎锁、Golden、作品内容、公开接口、容量规则或服务器预算；不调用付费接口，不额外清理磁盘。已有工作区及 G 盘恢复材料保留。真机故障尚未解决：最终仍须由所有者在同一 iPhone Safari 完成原定至少十分钟验收；未通过就保留失败证据，不以桌面/模拟测试替代。
