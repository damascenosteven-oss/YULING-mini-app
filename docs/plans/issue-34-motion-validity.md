# 布局随机化合法性修复
所有者于2026-10-31批准完整对话计划，PR33合并后实施。授权代码、测试、Issue分支推送和审核PR；不授权合并、服务器、部署、管理员初始化或付费调用。

我跑过：合法十页模拟样本在100个十六进制seed中51次随机化后违反结构约束，0000000000000001稳定复现。这不是线上失败率，也不能证明历史422全部同因。

## 实施与边界
共享解析器先校验输入和既有18个候选的结构、Skill、动效；合法候选才排序并执行近期/显式排除。无可选候选时最多18个原合法布局动效候选，仍校验/排除；均不可用受控失败，未知异常传播。保留内容、数据、来源、页序、Skill、长流程兼容限制和布局多样性。不新增模型调用、公开seed开关或旧作品签名拒绝规则。
换动效保留页面/版式，只返回匹配实际布局的motionPlan，排除当前与近期方案。大纲维持既有502格式；刷新补受控502，422/认证/限流不变。日志仅请求编号/固定步骤/分类。

## 验证
严格红绿：固定seed和100seed×四模式；六/十二页、连续要点、流程/树/数据图表、五种Skill及legacy；确定性/多样性/指纹、防排除耗尽和未知异常。故意恢复非法返回、忽略排除、吞异常必须被拒绝，再恢复通过。
隔离测试只固定动效8字节随机源，其余加密随机保持原样；真实HTTP登录→管理员→十页大纲→换动效→Python/Chrome QA→预览，外部模型/存储模拟、零搜索、模型最多两次。完整安装/validate/portable/跨仓库/geometry/build/两份审计/秘密扫描/门禁；最终严格权限镜像一核1GiB无额外swap、无OOM，两次独立十二页零差异。失败留证，不调整seed、阈值或预算避开。
