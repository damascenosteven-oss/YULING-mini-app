# iPhone Safari 轻量播放与生命周期

所有者于 2026-10-31 明确批准完整实施计划。触屏主指针且无悬停时启用轻量播放；不依赖 UA，横竖屏不改变模式。手机保留分步、翻页、自动播放、跳页，约 200ms 淡入淡出、内容入场不超过 350ms；移除粒子循环、重滤镜、旋转背景、3D 和扫描光幕。地图仅页码标题，系统减弱动态效果进一步取消装饰转场。电脑效果保持原样。

稳定只绘制当前页，转场最多一个离场页；取消过期回调并释放隐藏页动画。初始可见布局下测量图表，保留正文、图表和分步状态。管理播放器自己的前后台计时器，不修改全局动画 API。

应用共享 HTML 兼容处理覆盖新生成及旧课件读取，验证已知运行时签名和唯一插入位置；未知结构受控失败、固定错误分类。版本标记防重复，COS 原文、接口、分享码、CSP、iframe 隔离、引擎源码/锁和 Golden 均不变。

## 验证
真实作品仅作仓库外诊断样本，Git 使用无用户内容的模拟作品。严格红绿及故意变异覆盖隐藏动画、快速往返、重复处理/监听器、未知运行时、分步/图表/地图。真实分享 iframe 连续翻页 100 次、快速往返、转屏、自动播放和前后台恢复；检查当前页唯一、无残留离场页、隐藏动画为零、无粒子循环、节点/监听器不持续增长。Chromium 和可用 WebKit 不冒充 iPhone 验收。

完整工程、部署回归、冻结安装、validate、portable、跨仓库、geometry、build、两份 audit、秘密检查及最终镜像权限/Python/Chrome/模拟 HTTP；电脑两次独立十二页零像素差异。
