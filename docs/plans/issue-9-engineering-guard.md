推送 Issue 分支并开 PR；所有者负责合并、GitHub 分支保护以及后续服务器操作。

## 实现

- 保存与已安装版本逐字节相同的检查器快照、SHA256 和仅本 Issue 的脱敏批准策略。
- 用正式 install 入口登记共同 Git 目录，备份并串接原有钩子；关联工作树共享安装。
  未登记批准记录的 Issue 不允许提交。本轮不提前登记 Issue #8。
- pre-commit 检查暂存树；pre-push 检查待推送提交并禁止 main/master 写入或删除。
- Codex 继续使用既有适配器，实测拒绝与恢复，不修改全局适配器或客户端信任。
- PR CI 调用同版本检查器，绑定实际 head/base、分支及匹配的 Closes #编号。
- effective_at 保持 2026-10-22T04:50:03.733426+00:00，不添加历史 PR 或 Dependabot 豁免。
  不改私有台账、计数或检查器逻辑，不复制其他项目记录和秘密。
- GitHub 分支保护由所有者另行设置；工作流存在不代表检查已强制执行。

main 被拒绝；覆盖工作区已修复但暂存区仍错误。测试实际 Git 钩子、Codex 适配器
