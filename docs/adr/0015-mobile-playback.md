# 触屏轻量播放与应用层旧作品兼容

将移动端呈现兼容放在应用的生成/读取边界，共用有版本、严格签名校验的 HTML 处理；保留固定引擎和 COS 原文。触屏无悬停时仅降低装饰效果，不删除正文、分步或导航；桌面不启用兼容运行逻辑。

## Critic Loop
用户 iPhone Safari 翻页后重复崩溃；现有作品隐藏封面动画继续运行，本机诊断合成层 27→8，但 Chromium 未复现崩溃，不将推断当根因。维持现状 30/100 成本低但保留浪费；全静态手机 80/100 易控但损失分步体验；轻量动画与生命周期 92/100，保留体验，代价为严格运行时兼容签名及真机回归维护，采用。应用边界覆盖旧作品无需重生成，未知引擎显式失败而非盲目替换。

## 验收与恢复
隐藏页零运行动画，最多一个离场页，粒子不启动，地图不复制整页；快速切换/恢复不残留。桌面 Golden 不变。脚本变更必须更新明确兼容签名并通过真实 iframe 回归；合并后部署可恢复旧应用，COS 原文不变。只有所有者真机十分钟通过才确认 Safari 问题恢复。
