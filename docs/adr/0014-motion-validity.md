# 合法候选筛选与有界布局兜底
布局是页面的静态排版，动效是匹配实际页面的播放方案；刷新动效不改变布局。共享解析器负责在排序前维护合法性，而不是让后续构建拒绝已返回的大纲。

## Critic Loop
问题与证据：已校验模型输出被布局随机化破坏，固定十六进制seed1可复现；100样本51次失败（非线上比例）。维持现状35/100无维护成本但保留缺陷；取消布局变化65/100简单但损失多样性；采用合法18候选＋最多18原布局动效兜底92/100，增加有界本地校验、减少某些输入的可选多样性，换取合法结果和明确失败。保持既有结构、Skill及动效约束，不吞未知异常、不忽略排除。

## 兼容与验收
初次生成可改版式但不改内容；刷新只改动效且签名对应实际页面。旧作品不新增签名拒绝规则。接口成功形状不变；无候选受控502。100seed×四模式、排除穷尽/兜底/未知异常、HTTP至Python预览、严格镜像及零像素回归均须通过。此决定已由所有者批准；本轮只交付PR。
