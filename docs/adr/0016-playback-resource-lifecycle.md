# 保留原版手机视觉，按生命周期释放资源

所有者于 2026-11-01 明确批准，替代 ADR 0015 的手机轻量视觉决定。应用兼容边界继续用于生成和旧作品读取。

## Critic Loop

原播放器隐藏封面仍有运行动画；粒子在无绘制需求时继续申请帧；地图隐藏后保留完整副本。此前轻量实现关闭特效并替换缩略图，与最新目标不符。保持原样 40/100，成本低但浪费持续；轻量视觉 35/100，与已确认体验冲突；按页面/地图/后台生命周期管理 92/100，保留体验，代价是处理定时器、可见测量及快速切换竞争。

在已校验的固定运行时中进行有限、精确的调用点插装，登记播放器自身任务，不替换浏览器全局 API。保留原算法、CSS与时长。v2 校验原始及已知 v1 内容后转换，重复适配幂等；未知结构拒绝。地图保留轻量容器与一次绑定，副本仅在可见时挂载，关闭后释放。

## 验收和恢复

可见动画和地图对照原版；隐藏页无残留动画，后台无播放任务，重复循环资源不累加。故意引入节点/监听器泄漏及过期回调须被拒绝。保留严格镜像检查和桌面零像素差异。先提交PR由所有者合并；部署前核对G盘备份，切换失败恢复。只有真机完成原效果下十分钟测试才确认用户故障恢复。
