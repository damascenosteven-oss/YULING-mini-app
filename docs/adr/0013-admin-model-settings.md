# 管理员独立权限、服务器模型设置与普通生成

## Critic Loop

问题：关键词强制搜索阻止普通 PPT；环境变量缺少可见管理界面。证据：当前调用顺序与 requiresResearch 真实判断、只有邀请码认证、无持久设置挂载。

继续环境变量 60/100：实现成本低，但仍需服务器操作。浏览器保管密钥 35/100：无法全站统一管理且增加暴露风险。选择独立管理认证、服务器持久配置和无搜索普通生成 92/100：多维护认证、加密存储、出站限制与接收程序适配，换取手机可管理、重启不丢失和明确的模型边界。

## 决定与后果

单一全站配置；普通邀请码不授予管理权。服务器交互初始化管理员哈希，绑定密码摘要的独立一小时会话。API Key 使用现有 PPT_SESSION_SECRET 经域隔离派生的 AES-256-GCM 密钥加密；更换此秘密前须保留可用备份并先恢复/重新输入配置，不能将无法解密当作无配置。保存文件只允许运行 UID、0700/0600，目录绑定持久挂载，原子更新；候选容器只读。

Chat Completions + JSON 是接口合同，不承诺供应商原生协议或所有自称兼容的模型。公网 HTTPS 与固定 DNS 连接避免管理接口成为内网代理；不提供生产安全检查绕过开关。只有完整配置测试使用小额模型请求，保存不调用上游；测试通过不代表大纲/业务质量通过。

普通生成不自动联网，不将模型知识或自拟链接标为核验资料；旧作品的来源仍可展示。Cos 作品存储与模型设置职责分离，不迁移数据或修改 DeckOutline 结构。真实模型验收与部署另行授权。
