# 先测量三段链路，再决定传输方案

所有者批准手机触发的隔离测速，不批准改变发布运输方式或代理操作服务器。
现有 931635200 字节包在 2700 秒仅接收 67403620 字节。此为用户回传日志，不能据此单独归因于运营商或套餐。
代码核实受限入口只有 upload/deploy/status/rollback；随机探针不能绕过正式包校验。因此新增固定边界测速能力，保留发布协议 v2 兼容。

## Critic Loop

问题：完整包重复上传成本高，无法区分直传、COS 上行和服务器下载链路。
保持现状 25/100：无开发成本，但继续等待且无新信息。仅看监控 60/100：低成本但无法比较备选路径。
三段有界测速 90/100，接受：增加受限协议、专用 COS 权限和测试维护成本，但用小文件得出可复核的筛选证据。
不增加任意下载入口，不授予 SSH shell，不读取服务器应用秘密，不改变业务 API、正式引擎锁和图片基线。

同地域内网只是官方文档描述，需记录实际 DNS 和连接地址；不能把所有私有地址一概视为可信目的地。
只允许固定 COS 主机及本次运行对象，TLS 校验并禁止重定向；短期签名不记录。
三轮 4MiB，固定时限，禁止隐式重试；独立错误样本保留，完整性或权限问题停止。
清理仅本次对象；强制取消可能无法完成清理，报告已知对象并由所有者处理，不假报清理成功。

只有三轮完整且中转预计总时间≤30分钟、快≥4倍才建议另行做大文件测试；不自动切换生产发布。
