移动截图尚非逐像素一致，早期粒子阶段仍有差异；未将相位或栅格化推断认定为完整解释，也不将截图宣称为零像素通过。桌面 Golden 门槛没有修改；最终提交的严格权限、Python/Chrome、实际 HTTP 链路及两次独立十二页零像素捕获，必须由 `release-checks` 实际完成后才可验收。失败行号留证继续保留。
